# Инструкция по установке TechBlog

## Автоматическая установка

При первом запуске проекта на новом сервере автоматически откроется мастер установки.

### Шаги установки:

1. **Настройка базы данных**
   - Введите параметры подключения к MySQL
   - Нажмите "Проверить подключение"
   - Убедитесь, что база данных уже создана

2. **Настройки приложения**
   - Введите название блога
   - Введите URL сайта

3. **Создание администратора**
   - Введите имя администратора
   - Введите email
   - Создайте пароль (минимум 8 символов)

4. **Завершение**
   - Нажмите "Завершить установку"
   - Дождитесь завершения процесса
   - Вы будете перенаправлены на главную страницу

## Ручная установка

Если автоматическая установка не работает, выполните следующие шаги:

1. Скопируйте `.env.example` в `.env`
2. Настройте параметры базы данных в `.env`
3. Выполните миграции:
   ```bash
   php artisan migrate
   ```
4. Создайте администратора:
   ```bash
   php artisan tinker
   ```
   ```php
   User::create([
       'name' => 'Admin',
       'email' => 'admin@example.com',
       'password' => Hash::make('password'),
       'email_verified_at' => now(),
   ]);
   ```
5. Создайте файл-маркер:
   ```bash
   echo "installed" > storage/app/installed
   ```

## Удаление установщика

После успешной установки файл `storage/app/installed` создается автоматически. 
Этот файл блокирует повторный запуск установщика.

Для повторной установки удалите этот файл:
```bash
rm storage/app/installed
```

## Требования

- PHP >= 8.2
- MySQL >= 5.7
- Расширения PHP: pdo, pdo_mysql, mbstring, openssl, zip
- Composer
- Node.js и npm

## Безопасность

После установки убедитесь, что:
- Файл `.env` не доступен через веб-сервер
- Права на файлы установлены правильно
- APP_DEBUG установлен в `false` для production
